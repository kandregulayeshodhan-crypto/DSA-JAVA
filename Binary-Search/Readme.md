Binary Search

A collection of my Binary Search implementations in Java, focused on understanding core concepts, mastering problem-solving patterns, and developing efficient solutions for coding interviews.

Overview

Binary Search is an efficient searching technique that repeatedly reduces the search space by half. It is commonly applied to sorted arrays, monotonic search spaces, and optimization problems.

Topics Covered

- Binary Search Fundamentals
- Lower Bound and Upper Bound
- First and Last Occurrence
- Search in Rotated Sorted Arrays
- Finding Minimums and Peak Elements
- Binary Search on Answers
- Binary Search in Two-Dimensional Arrays
- Advanced Binary Search Patterns

Problem-Solving Approach

For each problem, I focus on:

- Understanding the problem and identifying its constraints
- Developing the brute-force approach where useful
- Deriving an optimized solution
- Analyzing time and space complexity
- Handling edge cases
- Performing dry runs to verify the logic
- Implementing the solution independently in Java

Key Concepts

- Search space and boundary management
- "low", "high", and "mid" pointers
- First and last valid positions
- Monotonicity and search-space reduction
- Binary search on answer ranges
- Integer overflow prevention
- Boundary conditions and edge cases

Language and Tools

- Platform: LeetCode, GeeksforGeeks, and other coding practice platforms
- IDE: Visual Studio Code

Goals

- Build a strong understanding of Binary Search patterns.

- Write clean, readable, and efficient Java solutions.
- Strengthen preparation for technical interviews.
