Hello World

Problem Statement

Write a Java program to print "Hello World" to the console.

Problem Link

"GeeksforGeeks — Hello World" (https://www.geeksforgeeks.org/problems/hello-world/1)

Difficulty

Easy

Objective

- Understand the basic structure of a Java program.
- Learn the purpose of the "main" method.
- Understand how to display output using "System.out.println()".
- Execute a simple Java program successfully.

Approach

1. Define a class named "GFG".
2. Create the "main" method, which serves as the program's entry point.
3. Use the standard Java output statement to display the required message.
4. Run the program and verify the output.

Sample Output

Hello World

Concepts Learned

- Java class declaration
- Main method and program execution
- Standard output
- Basic Java syntax

Complexity Analysis

- Time Complexity: O(1)
- Space Complexity: O(1)
